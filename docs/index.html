查缺补漏

松开，打开这张图片

  1. 框住要改的字在图片上拖出一个框，只包住文字和它的底色。一次框一种样式。
  2. 核对原文字中文、英文、中英混排都可以。用它比对出字体、字重、字号、字距和颜色。
  3. 输入新文字，点应用旧字被擦掉，背景补回来。字数相同，新字落在原来的位置；字数不同，保持原来的缩进、字距、间隔和行距。

双指缩放和移动图片；电脑上滚轮缩放，按住空格拖动。图片只在你的设备上处理，不会上传。原文字由页面自带的识别读出：常见的黑体、宋体和英文印刷体能读，手写体、艺术字读不准时请手动输入。也可以打开 PDF：一页一页地改，原文字直接取自 PDF，保存时新文字作为真正的文字写回 PDF，其它内容不变；同一个词要改多处时，用上面的“查找”逐处改，不会漏；图片和扫描页里的字，先点“识别图片里的文字”再查找。

打开、识别、改字、保存，全部在你的浏览器里完成。本应用没有后台服务器，不上传、不保存、不收集你的图片、PDF 和文字，也没有统计或广告代码。

应用只向本站请求程序和字体文件。网站由 GitHub Pages 托管，GitHub 会像其它网站一样记录访问日志（例如 IP 地址），这些记录不含你的图片和文件。

离线字体包和设置存在本机浏览器里，可以在“设置离线使用”里删除；删除这个网页的网站数据也会一并清除。
